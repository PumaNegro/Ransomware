# Laboratório de Cibersegurança: Simulação de Ransomware CLI 🛡️

Este repositório contém um conjunto de scripts educacionais desenvolvidos em Python e executados via linha de comando (CLI), criados para fins acadêmicos e de estudo em cibersegurança. O objetivo é compreender os mecanismos de criptografia simétrica aplicados ao sequestro de dados e avaliar as respectivas estratégias de recuperação e defesa.

> **⚠️ Aviso Legal:** Todo o código contido neste repositório possui caráter estritamente educacional, executado em ambiente de laboratório isolado e controlado. O uso destas técnicas sem autorização explícita é ilegal.
